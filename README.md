# AEGIS-X

**Evidence-Driven Security Intelligence Platform**

AEGIS-X is a security intelligence platform that combines deterministic security analysis, asset discovery, threat modeling, and AI-assisted reasoning to deliver actionable security assessments for web applications.

Unlike traditional AI security wrappers that rely purely on LLM-generated observations, AEGIS-X prioritizes evidence collection, rule-based analysis, and contextual risk assessment before generating recommendations.

---

## Features

### Asset Intelligence

* Asset discovery and attack surface mapping
* Technology stack fingerprinting
* HTTP header analysis
* Cookie inspection
* JavaScript asset enumeration
* Third-party dependency visibility

### Exposure Intelligence

* Security header validation
* Transport security analysis
* TLS configuration assessment
* Cookie security evaluation
* Public attack surface assessment

### Threat Intelligence

* Dynamic threat exposure graph
* Attack path generation
* Risk propagation modeling
* Threat-to-control mapping
* Security knowledge graph

### Risk Intelligence

* Attackability scoring
* Risk prioritization
* Security debt tracking
* Coverage analysis
* Confidence scoring

### Evidence Engine

Every finding generated by AEGIS-X is backed by collected evidence.

Examples:

* Missing Content Security Policy
* Missing HSTS
* Insecure Cookie Configuration
* Version Disclosure
* Weak Security Headers

### AI Security Copilot

LLMs are used as reasoning assistants rather than primary vulnerability detectors.

Model Chain:

* Gemma
* Llama
* DeepSeek
* OpenRouter Auto Fallback

## Security Analysis Pipeline

### 1. Discovery

Identifies:

* Pages
* Assets
* Technologies
* Cookies
* Headers
* Third-party services

### 2. Evidence Collection

Collects observable security artifacts and configuration data.

### 3. Rules Engine

Applies deterministic security checks against collected evidence.

### 4. Threat Modeling

Builds threat relationships and attack paths from findings.

### 5. Risk Scoring

Calculates:

* Risk Score
* Attackability
* Security Debt
* Coverage

### 6. Roadmap Generation

Produces prioritized remediation recommendations.

## Local Development

### Prerequisites

* Node.js 20+
* OpenRouter API Key

### Installation

```bash
git clone https://github.com/ChaitanyaAndhare/Aegis-X.git

cd Aegis-X

npm install
```

### Environment Variables

Create `.env`

```env
OPENROUTER_API_KEY=your_api_key
```

### Start Development

```bash
npm run dev
npm run dev:api
```

Frontend:

```text
http://localhost:5173
```

Backend:

```text
http://localhost:8787
```
